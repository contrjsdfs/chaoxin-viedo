# 视频播放辅助脚本

一个跑在浏览器控制台里的**播放辅助工具**:给在线课程视频锁定倍速,并在当前章节的视频全部播完后自动进入下一节。

## 重要声明

- **需要本人在场观看**。视频全程正常播放、平台正常计时,脚本不替你"看"视频。
- **不含**保活、后台挂机、页面可见性伪装、静音、反检测、伪造观看记录等功能。
- 请遵守所在平台与学校/机构的相关规定。若平台禁止此类辅助,请勿使用。
- 因使用本脚本导致的账号异常、成绩作废等后果,由使用者自行承担。

## 功能

- 锁定 `1.5x` / `2x` 播放倍速,播放器重置时会自动改回。
- 递归扫描所有层级的 iframe 定位视频(兼容 iframe 嵌套)。
- 同一章节有多个视频任务点时,依次播完所有视频后才进入下一节。
- 兼容"多个 `<video>` 元素"和"同一元素切换视频源"两种多任务点结构。
- 章节切换后自动开始播放下一个视频。
- 进入下一节时补齐目标页面缺失的函数,绕过其跳转报错。

## 使用方法

1. 打开课程页面,让视频开始播放。
2. 按 `F12` 打开浏览器控制台。
3. 把 `chaoxing-speed-helper.js` 的完整内容粘贴进控制台,回车。
4. 看到绿色 `[学习助手] 已启动` 即生效。启动时会打印扫描结果:

```
扫描结果：可访问框架 8 个，跨域 0 个，video 1 个
```

`video` 数量大于 0 表示已找到视频。

## 控制台命令

| 命令 | 作用 |
| --- | --- |
| `changeSpeed(1.5)` | 切换为 1.5 倍速(也可 `changeSpeed(2)`) |
| `toggleAutoNext()` | 开启/关闭自动进入下一节 |
| `diagFrames()` | 打印框架、视频数量及各视频进度 |
| `stopHelper()` | 停止脚本监听 |

## 常见问题

**扫描结果 `video 0 个`** — 视频可能在跨域 iframe 中,主页面脚本无权访问。可尝试在控制台顶部的上下文下拉框切换到视频所在的 iframe 再粘贴,或单独打开视频页面。若仍不行,说明该播放器完全跨域,纯控制台方案够不着。

**提示"自动播放被浏览器拦截"** — 浏览器要求用户先与页面交互才能自动播放。手动点一次视频的播放键即可,之后脚本能接管。

**视频加载到一半卡住(`ERR_CONTENT_LENGTH_MISMATCH`)** — 这是视频源服务器/CDN 的问题,与脚本无关。刷新页面或更换网络后重试,并重新粘贴脚本(刷新会使脚本失效)。

**"下一节"没反应** — 部分平台的按钮由 JS 事件处理,脚本会先补齐页面缺失的函数再点击。若某个平台结构特殊,可用 `diagFrames()` 查看状态后手动点击。

## 说明

本项目仅提供浏览器端的播放控制辅助,不涉及任何绕过平台验证、伪造学习记录的能力。
